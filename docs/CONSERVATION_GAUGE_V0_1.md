# DSIR G1 conservation and gauge-bookkeeping contract v0.1

Date: 2026-08-24

This document freezes the bookkeeping rules required before any cross-family law-discovery claim. It deliberately separates covariant identities from solver-specific gauge conventions.

## 1. Total conservation is the object that must be common across families

For a decomposition into components `i`, DSIR writes

`nabla_mu T_i^{mu nu} = Q_i^nu`,

with the hard internal-interaction identity

`sum_i Q_i^nu = 0`.

Therefore

`nabla_mu T_tot^{mu nu} = 0`.

A model that violates this identity without an explicitly declared external source, modified gravitational field equation, or non-covariant framework is not admitted as an ordinary interacting dark-sector control.

### IDE source convention already audited

For the pinned interacting-vacuum source convention

`Q/H = alpha rho_m + beta rho_v`,

`d rho_m/d ln a = -(3+alpha) rho_m - beta rho_v`,

`d rho_v/d ln a = alpha rho_m + beta rho_v`.

Adding the two equations removes the internal transfer exactly:

`d(rho_m+rho_v)/d ln a = -3 rho_m`,

which is the total continuity equation for pressureless matter plus vacuum with `p_v=-rho_v`. Thus alpha and beta redistribute energy internally but do not create or destroy total stress-energy.

## 2. Bianchi identities are projected out, not rediscovered

If a model is represented through an effective tensor `X_{mu nu}` in

`G_{mu nu} = 8 pi G (T_known_{mu nu} + X_{mu nu})`,

then the geometrical identity `nabla_mu G^{mu nu}=0` implies a conservation constraint on the total effective source. Any feature vector assembled from equations related exactly by this identity contains deterministic linear dependence.

DSIR therefore projects exact conservation/Bianchi identities before rank estimation. A singular direction generated only by such an identity is not a new dark-sector law.

## 3. Gauge transformations are handled at tensor level

For an infinitesimal coordinate shift generated by `xi^mu`, a first-order perturbation transforms as

`delta T_{mu nu} -> delta T_{mu nu} - L_xi Tbar_{mu nu}`,

where `L_xi` is the Lie derivative and `Tbar` is the background tensor.

This statement is convention independent. Solver variables such as density contrasts, velocity divergences and metric perturbations inherit gauge transformations from it.

### Consequence for the common response matrix

Raw solver-specific variables are NOT automatically common coordinates. In particular, raw versions of

- `delta_i`,
- `theta_i`,
- synchronous `h`, `eta`,
- Newtonian metric variables,

must not be concatenated across model families unless an explicit gauge-invariant mapping or a validated gauge transformation has been applied.

## 4. Observable and operationally gauge-safe channels

Background observables and directly observable combinations such as distance ratios, expansion ratios, redshift-space observables, lensing observables and CMB spectra are admissible once their component definitions and nuisance conventions are matched.

`P_m(k,z)` requires additional care. A solver may construct the matter source from gauge-dependent density variables, and two forks can use different gauges or component definitions. Therefore raw solver `mPk` is admitted to a cross-family basis only after BOTH conditions hold:

1. the clustering-matter component definition is matched;
2. a gauge audit demonstrates that the residual gauge dependence is below the frozen theory-regression tolerance on the declared scale domain, OR an explicitly gauge-invariant/comoving matter-density extractor is used.

The first DSIR gauge audit is implemented in `.github/workflows/gauge-baseline.yml` using the same pinned GDM_CLASS code and identical cosmology in Newtonian and synchronous gauges.

## 5. G1 sub-gates

- **G1-CONS:** internal transfer cancellation and total background conservation are explicit for every interacting family.
- **G1-BIANCHI:** exact conservation/Bianchi-derived coordinates are marked as deterministic identities and projected before rank discovery.
- **G1-GAUGE:** every perturbation channel in the common response matrix is either gauge invariant by construction or has a quantified gauge-error bound below its frozen domain tolerance.
- **G1-PROVENANCE:** solver commit, gauge, component definition and any gauge transformation are stored with each response vector.

G1 is PASS only when all four sub-gates pass. Until the matter-power gauge audit is resolved, G1 remains PARTIAL.

## 6. Discovery rule

No candidate G7 relation may be called nontrivial if it disappears after:

- conservation/Bianchi projection,
- gauge transformation or gauge-safe re-expression,
- component-definition matching,
- nuisance/calibration projection.

This is a hard anti-artifact rule for DSIR.
