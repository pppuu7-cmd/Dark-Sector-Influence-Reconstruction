# DSIR article readiness ledger v0.1

**Assessment date:** 2026-08-27  
**Purpose:** distinguish `enough evidence to start drafting` from `ready to submit` and from `discovery gate passed`.

This is a publication-management ledger, not a scientific significance test. It cannot promote G7/G8/G9.

## Readiness states

- `NOT_READY` — a central evidentiary dependency is missing.
- `READY_FOR_DRAFTING` — the repository contains enough evidence to write the complete scientific argument and methods for the stated article scope; figures/tables/text may still need manuscript production.
- `READY_FOR_INTERNAL_REVIEW` — draft, figure/table manifest, bibliography and reproducibility appendix are assembled.
- `READY_FOR_SUBMISSION` — internal scientific/novelty checks and manuscript packaging are complete.

## Minimum `READY_FOR_DRAFTING` criteria

For an article's own declared scope:

1. **Claim boundary frozen.** Allowed and prohibited claims are explicit.
2. **Core definitions/formulas archived.** The paper can be reconstructed without relying on chat memory.
3. **Quantitative evidence archived.** Key numbers resolve to repository data, workflow artifact or immutable upstream source.
4. **Reproducibility/provenance adequate.** Solver commits, run IDs and failure semantics are available for central claims.
5. **Negative controls/failures visible.** Central conclusions are not built only from successful examples.
6. **Prospective evidence exists where the paper uses predictive language.** Retrospective results are labelled as such.
7. **Prior-art boundary exists.** Draft wording can avoid already-known broad claims.
8. **No unresolved dependency can reverse the paper's central claim.** Open later-stage gates are acceptable only if explicitly outside scope.
9. **Chronology/recovery adequate.** The development path and selection chronology can be audited.
10. **Figure/table source data exist.** Final plotting may remain, but no central figure requires a new scientific experiment merely to support the paper's core thesis.
