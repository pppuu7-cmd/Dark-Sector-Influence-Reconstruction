`representation -> resolvability -> ray/line/subspace -> channel-conditioned equivalence -> physical support -> observational quotient`.

The key falsification sequence remains:

1. known-sector K2 weakens matter-only dark specificity;
2. static multi-channel augmentation does not generically cure the ambiguity;
3. temporal and velocity channels strongly separate a selected **positive-oriented K2 ray**;
4. fresh K2(-) falsifies promotion of that ray result to a two-sided nuisance-line specificity claim;
5. K1 primordial tilt is a kernel direction of transfer-only `t_tot`, so no scientific angle is defined there;
6. after restoring the primordial-power contribution, the resolved K1 nuisance line still overlaps the tested GDM rays;
7. therefore specificity depends jointly on representation, resolvability and nuisance geometry, not merely on the existence of a large oriented theory-space angle.
