## Scientific-source rule

Every quantitative manuscript statement must resolve to a preregistered experiment and immutable artifact, a pinned source/provenance theorem, an explicitly labelled retrospective analysis, or an immutable observational product. Missing identifiers are left missing rather than inferred.

## Failure semantics

Physical FAIL, exact null, `INVALID_FOR_SCIENCE`, incomplete work and infrastructure recovery remain distinct. Negative results stay visible in the manuscript.

## Discovery boundary
