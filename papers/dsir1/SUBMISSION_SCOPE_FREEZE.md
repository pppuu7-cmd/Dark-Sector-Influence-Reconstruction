# DSIR-I submission scope freeze — v0.1

**Date:** 2026-08-27  
**Purpose:** prevent active DSIR research from automatically expanding the first paper whenever a newer experiment completes.

DSIR-I is a response-geometry / identifiability / failure-resistant-methodology paper. New repository results enter it only when they are necessary to support, falsify, or delimit that thesis. Chronological recency alone is never a reason for inclusion.

## 1. DSIR-I core — main-text eligible

The first paper's main scientific center is frozen to:

1. block-aware heterogeneous response atlas;
2. additive scale+time core failure and irreducible `k x z` response structure;
3. finite-amplitude `chi_I` hierarchy and deterministic node robustness;
4. channel-conditional degeneracy breaking;
5. response-manifold curvature and the distinction among microscopic, manifold, representation and discriminant dimensions;
6. WDM/DCDM mechanism-diversity controls;
7. prospective F27 common-scalar-law falsification;
8. formal channel-conditional equivalence through `A_B=Q_BW_BK_B`;
9. concise observation-route admissibility result showing that a formal quotient may not be evaluated before finite normalization, exact realized-operator reproducibility, physical support and provider semantics;
10. preserved provider/scientific FAILs as part of reproducible methodology.

A completed new result may enter the DSIR-I main text only if omitting it would make one of these ten statements materially inaccurate or misleading.

## 2. DSIR-I supplement / provenance eligible

Detailed implementation chronology may be retained without becoming a headline result. Current examples include:

- Exp073M candidate-class identification;
- Exp073N exact-realization provenance FAIL;
- Exp073O prospective public replacement;
- Exp073P2 exact public-input binding;
- Exp073S0 mask and `n(z)` reproduction;
- Exp073R0 raw-row/HEALPix equivalence PASS;
- infrastructure-incomplete attempts that demonstrate unchanged retry criteria.

These are useful because they document fail-closed methodology. They do not convert DSIR-I into a full survey-inference paper.

## 3. Default defer to DSIR-II or later

Unless a result changes a DSIR-I limitation, the following belong to later papers by default:

- completed physical-support scoring for the replacement real-data route;
- full covariance restriction and whitening;
- nuisance tangent construction, frozen rank rule and nuisance quotient;
- survey-level covariance-weighted or nuisance-quotiented model distances;
- actual survey detectability/significance claims;
- optimized discriminant sets under final observational covariance;
- observation-space relation/null tests that require the completed quotient.

These define the natural DSIR-II observation-space programme.

## 4. Default defer to DSIR-III or later

The following are not DSIR-I claims even if discovered while DSIR-I is being prepared:

- a candidate model-independent residual/universal relation closing G7;
- a genuinely fresh withheld-family validation capable of closing G8;
- a universal dark-sector invariant/no-hair-like statement;
- reconstruction of underlying dynamics, field equations, action or Lagrangian;
- G9 closure;
- a defensible claim of new fundamental physics.

Such results require their own prospective evidence chain and should remain publication assets for later DSIR papers.

## 5. Decision rule for every new experiment

When a new completed frozen result appears in `main`, classify it before editing DSIR-I:

### A — main-text update

Use only if it changes the truth, scope, or strongest evidence of an already frozen DSIR-I core claim.

### B — supplement/provenance update

Use if it improves reproducibility, explains a failure/replacement, or closes a prerequisite without producing the later survey-level scientific object.

### C — defer

Use if it advances support/covariance/nuisance/relations/dynamics beyond what DSIR-I needs for its own thesis.

### D — exclude

Use if the run is infrastructure-incomplete, post-hoc, insufficiently reproducible, or otherwise not a completed scientific result.

The classification itself should be recorded in the paper recovery history when material.
