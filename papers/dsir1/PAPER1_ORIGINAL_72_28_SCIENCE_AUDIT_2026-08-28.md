# DSIR-I — audit of the original 72/28 scientific-plan estimate

**Date:** 2026-08-28  
**Purpose:** distinguish the historical broad Paper-I scientific plan from the later narrowed declared DSIR-I manuscript scope and from editorial/submission readiness.

## 1. Why this audit exists

An earlier project-status estimate described Paper I as approximately **72% complete / 28% remaining**. That historical estimate predates the later publication architecture that split DSIR into a staged paper series and deliberately narrowed DSIR-I to observable-response geometry / identifiability.

The old readiness discussion grouped the unfinished work into six broad blocks:

1. unified response map;
2. amplitude / zero / transition atlas;
3. cross-model translator;
4. withheld-family validation;
5. central scientific narrative;
6. compact figures / tables.

The exact old per-row weights were not archived in the repository. Therefore this audit does **not** invent a retroactive weighted percentage. It uses an explicit equal-block rubric only to answer the present management question: how much of the old 28% has actually been scientifically recovered by the current repository?

This audit cannot promote G7/G8/G9 and cannot silently expand the frozen manuscript claim boundary.

## 2. Scoring rubric

For the six historical blocks only:

- `CLOSED = 1.00` — the scientific question needed for the broad Paper-I block is repository-resident and evidence-backed;
- `HIGH_PARTIAL = 0.75` — the architecture and substantial evidence exist, but the strongest originally imaginable version still requires a prospective/observational completion;
- `PARTIAL = 0.50` — important evidence exists but a central dependency is still missing;
- `OPEN = 0.00` — the intended scientific result is not established.

The current equal-block score is the mean of these six values. A sensitivity band is reported by allowing `HIGH_PARTIAL` to range from `0.67` to `0.83`; this prevents false precision.

## 4. What happened to the old 28%

The old 28% was not simply discarded by narrowing the paper. Most of it was actually worked through after the historical estimate.

### Scientifically recovered

- finite-amplitude interaction/curvature and leave-one-node robustness;
- WDM high-k atlas and withheld cutoff interpolation;
- genuinely withheld DCDM temporal-localization test;
- prospective C7/IDM-DR falsification of a common scalar rule;
- fresh C9/F30 multicoordinate response-path test;
- known-sector K2 specificity control showing matter-space simplicity is not dark-specific;
- local channel-conditioned translator mechanics and cycle/Jacobian diagnostics;
- formal channel-conditioned equivalence / nuisance-quotient language;
- physical-eligibility-before-covariance failure chain;
- mechanism-to-response synthesis with prior-art boundary;
- moving-characteristic-scale analytic bridge and frozen WDM retrospective consistency test;
- reproducible figures/tables and claim-level provenance.

### Still genuinely open from the strongest old vision

1. **Translator validation beyond retrospective proof-of-concept.**  
   A preregistered translator needs a frozen coordinate/metric definition and a fresh cross-family or held-out validation. A survey-precision claim additionally requires physical support, covariance and nuisance quotient.

2. **Full observational G7 -> fresh G8 chain.**  
   Current observation-route work has closed many prerequisites and, importantly, preserved multiple support/provider/provenance failures. But the realized DES replacement route has not yet produced the completed physical-support -> covariance restriction/whitening -> nuisance quotient -> frozen G7 relation/null -> genuinely fresh G8 sequence.

These are real scientific tasks, but under the current publication architecture they belong primarily to later DSIR papers. They must not be used to relabel the present narrow DSIR-I scientific core as incomplete.

## 6. Consequence for the first article

The article already has enough scientific evidence for its frozen thesis. The most useful remaining research work for **Paper I itself** is therefore not to force G7/G8 into the manuscript, but to strengthen the two HIGH_PARTIAL historical blocks only where the strengthening can be done without scope leakage:

1. convert the current translator proof-of-concept into a stricter frozen robustness audit using already-frozen response products, if this can be done without selecting a metric after seeing outcomes;
2. maintain a fail-closed intake rule for any completed DSIR4/Exp073 result: admit it only if it materially changes an explicit Paper-I limitation;
3. keep the completed G7/G8 observational program active on `main` as later-paper science.
