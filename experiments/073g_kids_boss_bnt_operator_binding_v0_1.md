## BNT convention

The five published KiDS source histograms store the lower redshift-bin edge.
Use the lower edge plus half the constant bin width as the integration point,
then normalize each `n(z)` to unit trapezoidal integral.

Construct the BNT matrix exactly as in the pinned public `x-cut` convention:

- row 0 is the identity row;
- row 1 is `[-1,1,0,0,0]`;
- each row `i>=2` has support only on source columns `i-2,i-1,i` and nulls
  both the zeroth and inverse-comoving-distance moments.

Rows 0 and 1 are excluded prospectively because they do not satisfy both
localization moments. Retain only zero-based transformed rows `[2,3,4]` for
the support audit. This choice is fixed before looking at leakage.

Apply `M C_ell M^T` to cosmic shear and apply `M` only to the source-shear
index of galaxy-galaxy lensing. Density clustering is not BNT transformed.
The public-matrix nulling tolerance is `1e-10`; repeated construction must be
deterministic to relative tolerance `1e-12`.

`src/dsir/bnt.py` implements only this algebra and its controls. It does not
contain a support threshold or read an observation/covariance vector.

## Frozen lens and density selection

The published fiducial BOSS construction uses its disjoint low/high pair; the
intermediate bin is explicitly a strongly overlapping diagnostic alternative.

- retain only BOSS high-z clustering, `0.5<z<0.75`;
- retain only BOSS/2dFLenS GGL lens bin 2, nominally `0.5<z<0.75`;
- exclude the released low-z clustering/lens bin `0.2<z<0.5` before support
  evaluation because it materially crosses the frozen `z_min=0.295` boundary;
- do not add the overlapping intermediate BOSS diagnostic bin.

No covariance entry was used for these choices.
