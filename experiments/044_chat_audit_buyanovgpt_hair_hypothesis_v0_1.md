## Ideas from the chat that must be preserved as hypotheses

### H-A — observable coordinates need not equal microscopic parameters

A theory parameter such as `w`, `alpha`, `beta`, `cs2`, `cv2`, WDM mass or `B0` is not automatically an observable coordinate. Repeated DSIR results support the more general map

`microphysics -> residual source -> multi-channel response trajectory`.

This is already consistent with hard findings F1/F8, but the specific low-dimensional coordinates below remain hypotheses.

### H-B — dark-sector no-hair analogy

The chat introduced a deliberately limited analogy with black-hole no-hair ideas: many microscopic realizations might project onto a much smaller observable response space. DSIR does **not** assert a no-hair theorem for the dark sector. The falsifiable question is only whether a small, stable set of response coordinates spans the validated atlas after observational/gauge/precision stress tests.

### H-C — distinguish representation rank from discrimination rank

Two separate questions must never be conflated:

- `N_repr`: how many response coordinates are needed to approximate/reconstruct the response vectors;
- `N_disc`: how many independent channels are needed to distinguish physically different mechanisms.

They need not be equal. GDM `cs2/cv2` is already a hard warning example: density/growth responses are nearly collinear while metric slip separates them.

### H-D — candidate Core + Activation organization

The chat proposed a **candidate**, not yet validated, organization:

- Core types: `G` (growth/amplitude), `T` (scale/transfer structure), `tau` (time evolution);
- Activation/mechanism channels: `S` (metric slip / anisotropic stress), `M` (small-scale/free-streaming localization), `N` (interaction/non-conservation information).

This notation is provisional. In particular:

1. `G`, `T`, and `tau` are not yet proven independent coordinates;
2. `T` and `tau` can both be derived from the same full `r_Delta(k,z)` field and may contain a non-separable scale-time interaction not representable by three additive pieces;
3. `S`, `M`, and `N` are not simple on/off Boolean parameters in general;
4. C4 WDM does not currently share the same informative low-k `(k,z)` block as C1/C2/C3/C5, so it cannot be silently inserted into a common low-k matrix;
5. the current hard discriminator graph `{metric slip, small-scale transfer, time/sign evolution}` is a minimum hitting set for the current evidence graph, not proof that the dark sector has exactly three parameters.

## Corrected operational meaning of `(G,T,tau)`

To make the chat hypothesis testable, Experiment 045A decomposes each common-grid structure response matrix `R(z,k)` into an orthogonal two-way additive form

`R(z,k) = mu + T(k) + tau(z) + I(z,k)`

with zero-mean constraints on `T` and `tau`.

Interpretation:

- `mu` = global growth/amplitude component (`G` in the narrow operational test);
- `T(k)` = scale-only component;
- `tau(z)` = time-only component;
- `I(z,k)` = irreducible scale-time interaction.

The candidate core is therefore the additive subspace `mu + T + tau`. A substantial `I` directly falsifies the claim that full structure information is captured by the three additive core types on that block.

This decomposition is a **diagnostic coordinate test**, not the final universal model.
