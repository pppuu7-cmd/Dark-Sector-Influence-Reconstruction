### Physical meaning of B0

For designer f(R), the standard dimensionless Compton-wavelength parameter is

\[
B(a)=\frac{f_{RR}}{1+f_R}\,\frac{R' H}{H'}
     =\frac{f_R'}{1+f_R}\,\frac{H}{H'},
\]

and

\[
B_0=B(a=1).
\]

Thus B0 controls the present scalaron Compton scale. The historical BZ-like control remains a QS diagnostic only; H-EFTCAMB evolves the full linear dynamics.

## Output-precision audit and internal threshold

The standard interpolated CAMB matter-power exporter uses `Transfer_GetMatterPowerS`, which computes internally through a double-precision helper and then explicitly casts the output array to single-precision `real` before text export. Expanding the text format from E15.6 to E25.16 therefore exposes binary32 values but cannot restore lost precision.

A separate output-only audit confirmed this behavior. It also showed that B0=1e-8 and exact B0=0 produce the same core response at the exported precision.

This is physically consistent with the pinned H-EFTCAMB configuration:

`EFTCAMB_GR_threshold = 1e-8`.

For B0=1e-8, the log reports `Return to GR time = 1.1`, so perturbations remain on the GR branch through today. For B0=1e-7, `Return to GR time ~= 0.7832`, and the model develops a nonzero scale-dependent response.

Therefore DSIR must not use B0<=1e-8 as a nominally nonzero f(R) atlas point. The pilot nonzero family should stay safely above the solver Return-to-GR threshold.
