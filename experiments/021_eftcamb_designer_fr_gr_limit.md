## Output-precision audit and internal threshold

The standard interpolated CAMB matter-power exporter uses `Transfer_GetMatterPowerS`, which obtains a double-precision result and then casts the output array to ordinary `real` before text export. Expanding only the text format therefore cannot restore precision already lost at this interface.

The pinned configuration also has

`EFTCAMB_GR_threshold = 1e-8`.

For `B0=1e-8`, the log reports `Return to GR time = 1.1`, so perturbations remain on the GR branch through today. For `B0=1e-7`, `Return to GR time ~= 0.7832`, and the model develops a nonzero scale-dependent response.

Therefore:

\[
\boxed{B_0\le10^{-8}\ \text{is not an independent nonzero atlas point in this pinned implementation}.}
\]
