# Exp073H — Beutler DR12 full-shape Fourier fallback binding v0.1

**Date:** 2026-08-27  
**Scope:** pre-support source/operator inventory under the already-frozen Exp073H candidate order.

The preferred official Grieb archive was immutably reproduced but contains no window/operator objects despite the SDSS results page describing window functions for the analysis. Therefore Exp073H proceeds to its prospectively frozen fallback class: an official BOSS DR12 Fourier-space power-spectrum multipole release with explicit k coordinates and public window/operator objects.

Official fallback archive target:

`https://data.sdss.org/sas/dr12/boss/papers/clustering/Beutler_etal_DR12COMBINED_fullshape_powspec.tar.gz`

This archive is listed in the same official SDSS DR12 clustering directory. The binding run records archive and object SHA256 values, numeric metadata for non-covariance ASCII objects, and candidate measurement/window paths. Covariance numerical contents are not read.

No support fraction is evaluated in this phase. H1-H8 classification is deferred until the immutable inventory is available.
