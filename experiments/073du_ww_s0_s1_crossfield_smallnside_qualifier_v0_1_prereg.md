# Exp073DU — WW_S0_S1 distinct-field small-NSIDE production-adapter qualifier v0.1

Status: preregistered support-only gate. This experiment is not an Article-3 science gate and has accounting `+0/+0`.

## Purpose

Qualify the exact production window adapter for the first distinct-source spin-2 cross field, `WW_S0_S1`, before any full-resolution `NSIDE=4096` A/B science launch. The gate is deliberately small-NSIDE and GitHub-hosted so it cannot compete with the active self-hosted Exp073DT `WW_S0_S0` science run.

The specific failure mode being tested is silent collapse of the ordered cross-field workspace `compute_coupling_matrix(S0,S1,b)` into either auto workspace `S0,S0` or `S1,S1`, or an adapter arithmetic mismatch after the workspace is serialized to FITS.

## Frozen qualifier geometry

- synthetic deterministic masks only; no DES science map is imported;
- `NSIDE=16`;
- `nl=48` (`ell=0..47`);
- deterministic band edges generated by the qualifier: `[0,6,12,18,24,30,36,42,48]`;
- both fields are spin-2 mask-only `NmtField` objects;
- `ncls=4`;
- selected production slice is exactly `wins[0,:,0,:]`, semantics `EE<-EE`;
- dtype for canonical selected payload: little-endian float64 (`<f8`).

## Required constructions

The same process must construct four workspaces from two demonstrably distinct masks/field objects:

1. ordered cross `W01 = workspace(S0,S1)`;
2. reverse cross `W10 = workspace(S1,S0)`;
3. auto `W00 = workspace(S0,S0)`;
4. auto `W11 = workspace(S1,S1)`.

`W01` is then written to FITS and passed through the frozen production exact adapter and frozen mmap downstream. Direct PyMaster `get_bandpower_windows()` from the in-memory `W01` is the reference for this qualifier only.

## Fail-closed PASS contract

The only PASS token is:

`PASS_EXP073DU_WW_S0_S1_CROSSFIELD_SMALLNSIDE_EXACT_ADAPTER_V0_1`

PASS requires all of the following to be true simultaneously:

- S0 and S1 synthetic masks are not `numpy.array_equal`;
- field objects are distinct objects;
- `W01` coupling matrix is not exactly equal to `W00`;
- `W01` coupling matrix is not exactly equal to `W11`;
- adapter full window is exactly `numpy.array_equal` to direct `W01.get_bandpower_windows()`;
- adapter selected `EE<-EE` is exactly `numpy.array_equal` to direct `W01[0,:,0,:]`;
- selected payload SHA256 equals canonical direct selected SHA256;
- shapes are exactly `[4,8,4,48]` and `[8,48]`;
- all direct and adapter values are finite;
- adapter receipt declares `no_tolerance_rescue=true`;
- runtime is PyMaster 2.7 and frozen source lineage validates.

No tolerance, rounding, smoothing, averaging, approximate equality, or post-hoc rescue is permitted.

## Orientation observation is non-gating

Exact equality or inequality of `W01` versus `W10` is recorded diagnostically but is **not** a PASS requirement. The purpose of this gate is to prove that ordered distinct-field construction is preserved and that the exact adapter reproduces the resulting workspace; it must not manufacture an asymmetry requirement not present in NaMaster.
